# JobTrack

A simple and responsive Job Application Tracker built with vanilla JavaScript.

JobTrack allows users to manage their job applications, track application statuses, search and filter applications, and keep their data saved locally in the browser.

## Features

- Add new job applications
- Edit existing applications
- Delete applications
- Track application status
- Search by company or position
- Filter applications by status
- Sort applications by date
- Dashboard statistics
- Persistent data using Local Storage
- Form validation
- Empty state handling
- Responsive user interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage
- Git & GitHub
